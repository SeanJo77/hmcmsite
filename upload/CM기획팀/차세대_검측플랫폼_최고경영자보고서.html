Sat-Pointer

✨ 기대 효과: 위치 조작 원천 차단

[작동 원리] 스마트폰과 연동된 고정밀 RTK 위성 신호를 통해, 현장의 절대 좌표를 시스템으로 실시간 전송합니다.

[시스템 적용] 기존 수기 입력 방식으로 발생하던 '위치 허위 입력'을 차단합니다. 도면상 허가된 오차 반경 내(Geo-fencing)에 진입해야만 검측 데이터 등록이 활성화되도록 시스템을 통제하여, 현장 방문 없는 탁상 감리를 물리적으로 방지합니다.

CUPID

✨ 기대 효과: 검측 사진 도용 방지

[작동 원리] 사진 촬영 즉시 메타데이터(EXIF)에 위경도 좌표, 시간, 그리고 카메라가 바라본 방향각(Compass) 정보를 암호화하여 전송합니다.

[시스템 적용] 수집된 데이터는 3D 도면 상에 해당 방향을 가리키는 시각적 화살표로 역투영됩니다. '어디서 어느 쪽을 바라보고 찍었는지'가 공간 상에 영구 박제되므로, 과거 타 구역 사진을 파일만 바꿔치기하여 허위로 첨부하는 관행을 100% 차단합니다.

기성객체모델

✨ 기대 효과: 서류 무인화 및 통합 관제

[작동 원리] 단순 시각용 3D 도면이 아닌, 도면을 이루는 개별 부품(말뚝, 기둥 등) 자체가 고유 속성 데이터를 품고 있는 데이터베이스로 작동합니다.

[시스템 적용] 현장에서 객체를 클릭하기만 하면 설계 기준값이 검측 서류에 100% 자동 매핑(Auto-Mapping)되어 단순 반복 타이핑 업무가 사라집니다. 최종 승인 즉시 3D 모델의 상태 색상이 변하고 대시보드 통계가 실시간으로 갱신되어 직관적인 통합 관제가 가능해집니다.

💡 전체 프로세스 혁신 포인트 (현행 vs 기획안)

  • 데이터 흐름의 연속성: (현행) 종이 도면 실측 후 사무실로 복귀해 서류를 수기 작성하며 데이터 단절 ➔ (기획안) 기성객체 클릭(의뢰) ➔ 모바일 정밀 측위(현장) ➔ 대시보드 갱신(승인)으로 끊김 없는(Seamless) 통합 체계 구축
  • 결재 결과의 자산화: (현행) 결재 완료 후 PDF 파일이 단순 저장소에 사장되어 현황 파악 불가 ➔ (기획안) 검측 승인 시 3D 디지털 트윈 및 2D GIS 대시보드에 결과가 실시간 시각화되어 직관적인 원격 관제 가능

검측시스템 데이터 연동 체계 (Auto-Mapping Architecture)

✅ 시스템 자동 매핑 (Auto-Mapping) 사무실/시스템 자동 생성

1. LOIN 기반 연동 (기성객체모델)

  • 공종 및 객체명: A시트(OBS마스터)의 [Process Name], [Element Object] 열 참조
  • 위치 좌표 (STA): E시트(시공단계)의 [Location] 열 참조
  • 설계 치수 및 기준값: E시트(시공단계)의 [Information] 열 참조
💡 적용 조건: 실측치 연결 규칙은 가설재(거푸집 등)를 제외한 '영구 잔존 요소객체'에 한해서만 적용 가능하도록 구조화되어 있습니다.

2. 별도 DB 기반 연동 (검측절차서/QMS)

  • 체크리스트 폼 & CodeNo: QMS-0085 매뉴얼 매핑 테이블 호출
  • 필수 검측(HP/WP) 등급: 검측 절차서 DB를 통해 자동 지정
  • 공정 Interlock (선행공정 통제): 검측 절차서에 명시된 선후행 작업 과정에 따라 미완료 건 자동 차단
💡 구축 방향: 복잡한 WBS나 공정표 연동은 배제하고, 검측절차서 상의 WP/HP 항목만으로 선후행 작업 과정을 1차 단순 분류하여 구축하며, 정밀한 통제 모듈은 추후 필요 시 고도화 과제로 진행합니다.

3. 첨부 서류 연계 (문서 자동화)

  • 표준 문서 (정적): ex-SSOC 시스템과 같이 [Process Name] 키워드 기반 태그 매칭을 통해 설계실무지침, 안전가이드 등을 자동 첨부합니다.
  • 필수 서류 누락 체크(Hard-Lock): LOIN E시트 [Documentation] 열(측량성과, 다짐시험 등) 기반으로 필수 서류 팝업 통제

❌ 현장 직접 입력 (Manual Input) 자동 매핑 불가

객체 모델이나 절차서만으로는 알 수 없는, 당일 현장의 실제(As-Is) 상황을 기록하는 동적 데이터입니다.

1. 실측 데이터 (동적)

  • 현장 실측치: 토공량, 다짐도, 규격 편차 등은 작업자가 직접 판단/입력
  • 기상 및 투입 현황: 당일 기상, 투입 장비·인원 수기 기입

2. 증빙 및 인증

  • 검측 증빙 사진 (CUPID): 갤러리 업로드 불가, 현장 앱 실시간 촬영 및 EXIF 해시 암호화 적용
  • 다단계 서명: 권한별(시공사/감리단) 전자서명 직접 수행

3. 동적 첨부 서류 (수동 첨부)

  • 현장 발생 문서: 당일 발급된 품질시험 성적서, 자재 송장, 특이사항 사유서 등은 현장에서 수동 촬영 및 첨부 필수.
💡 추후 고도화 가능성: LIMS(품질관리시스템) 연동 시, 해당 현장 시험 성적서는 시스템에서 자동으로 호출 가능하도록 확장 가능.

단일 데이터베이스(OBS) 기반 아키텍처

  • Presentation Layer: 시공사, 감리단, 발주처가 분리된 시스템을 쓰지 않고 하나의 화면 모듈에 권한별로 접속합니다.
  • Application Layer: 결재 엔진, 맵핑 엔진, 통계 엔진이 독립적인 API 형태로 제공되어 확장이 용이합니다.
  • Data Layer: 단순 파일 저장이 아닌, 3D 기성객체모델(DB)을 중심으로 모든 서류와 사진 데이터가 관계형으로 묶여 저장됩니다.
