# 검측_자료통합_프로세스_v9

> **💡 검측(Inspection)이란?**
> 건설 현장에서 특정 공종의 시공이 완료되었을 때 다음 후속 공정으로 넘어가기 전, 해당 시공물이 **설계도면, 시방서 및 각종 품질 기준에 적합하게 시공되었는지를 현장에서 실측·확인하여 합격/불합격 여부를 최종 판정하는 핵심 품질관리 절차**를 의미합니다.

---

검측 프로세스를 입체적으로 파악하기 위해, 참고한 주요 폴더 및 파일자료를 분류하였습니다.

## 2장. 통합 검측 프로세스 (ex-SSOC 연동 플로우차트)

> **💡 ex-SSOC 검측 화면 핵심 기능 (6대 탭)**
> 
> *   **검측의뢰서/통보서 검토**: 의뢰자가 입력한 공사명, 검측번호, 위치, 주요 내용을 시스템 내장 뷰어로 확인합니다.
> *   **체크리스트 판정**: 대공종 및 세부 코드별 표준 체크리스트의 적합 여부를 판정하며, 감사지적/설계지침이 자동 연동됩니다.
> *   **검측의뢰서 첨부서류**: 도면, 발파계획서 등 업로드된 PDF/CAD 파일을 웹 화면 상에서 즉시 열람합니다.
> *   **사진대지**: 현장에서 촬영한 시공 사진을 등록하고 사진명과 촬영일자를 연계하여 관리합니다.
> *   **3D Viewer (BIM)**: 3D BIM 뷰어를 내장하여 객체를 마우스로 클릭하고 이를 검측의뢰서와 매핑합니다.
> *   **반려 사유**: 보완 요청 및 불합격 판정 시 반려 사유를 명시하여 재검측의 이력을 기록합니다.

위 시스템 화면을 통해 검측 지점 도달 시, 배정된 등급별로 아래 매뉴얼 현장 흐름과 IT 시스템 상태값이 매핑되어 세부 프로세스가 수행됩니다.

### 2.1 상시검측 (WP)

```text
(현장 매뉴얼) [작업자] 시공 완료 ──▶ [공종담당자] 1차 확인/의뢰 ──▶ [공사책임자/품질관리실장] 검측/판정 ──(YES)──▶ 시공자 확인 및 대장 기록
(ex-SSOC)                             ┗[시공사 검측중]┛            ┗[시공사 확인완료]┛                ┗[시공사 통보완료]┛
```
*(※ 감독원은 실시간 입회 대신, 수시 점검 및 상시검측 관리대장 사후 확인을 수행)*

**[상시검측 5W1H 요약]**
- **Who (누가)**: 검측자(원도급사 공사책임자/품질관리실장)가 실측 판정, 시공자(현장대리인) 확인
- **When (언제)**: 절차서상 WP(상시검측)로 지정된 단계 도달 시
- **Where (어디서)**: 해당 공종 시공 현장
- **What (무엇을)**: 중요도가 상대적으로 낮거나 반복적인 시공 구조물
- **Why (왜)**: 시공사 자체 점검을 통한 품질 확보 및 감독원 업무 효율화
- **How (어떻게)**: 자체 실측/판정 후 상시검측 관리대장에 기록 (감독원은 사후 승인)

### 2.2 필수검측(공구) — 감독원이 직접 검측

```text
(현장 매뉴얼) [작업자] 시공 완료 ──▶ [공종담당자] 1차 확인 ──▶ [공사책임자] 2차 확인/의뢰 ──▶ [감독원(건설사업관리기술인)] 합동 실측/판정 ──(YES)──▶ 통보서 발급
(ex-SSOC)                                                     ┗[시공사 의뢰완료]┛           ┗[감독원 접수완료/검측완료]┛             ┗[감독원 통보완료]┛
```

**[필수검측(공구) 5W1H 요약]**
- **Who (누가)**: **감독원(건설사업관리기술인)**이 최종 판정
- **When (언제)**: 절차서상 공구용 HP(필수검측)로 지정된 단계 도달 시
- **Where (어디서)**: 해당 공종 시공 현장
- **What (무엇을)**: 매몰 부위나 구조 기능상 핵심이 되는 주요 구조물
- **Why (왜)**: 하자가 발생하면 복구하기 힘든 중요 공종의 안전성 담보
- **How (어떻게)**: 시공사 의뢰(ex-SSOC) → 감독원) 현장 합동 실측 및 채점 → 통보서 발급

### 2.3 필수검측(사업단) — 본사 직할 조직이 직접 검측

```text
(현장 매뉴얼) [작업자] 완료 ──▶ [공종담당자] 1차 확인 ──▶ [공사책임자] 2차 확인 ──▶ [감리 또는 감독원] 3차 확인/의뢰 ──▶ [공사시행부서원] 실측/판정 ──(YES)──▶ 통보서 발급
(ex-SSOC)                                                ┗[시공사 의뢰완료]┛     ┗[감독원 의뢰완료]┛               ┗[사업단 접수/검측완료]┛           ┗[사업단 통보완료]┛
```

**[필수검측(사업단) 5W1H 요약]**
- **Who (누가)**: 공사시행부서원(본사 직할 사업단/본부 등 소속 직원)이 최종 판정
- **When (언제)**: 절차서상 사업단용 HP(필수검측)로 지정된 단계 도달 시
- **Where (어디서)**: 해당 공종 시공 현장
- **What (무엇을)**: 사업단 차원의 교차 검증이 필요한 최상위 중요 구조물
- **Why (왜)**: 감리(또는 감독원)에게 집중된 권한의 분산 및 본사 조직의 철저한 다중 교차 점검
- **How (어떻게)**: 감리(또는 감독원) 경유 상위 의뢰 → 공사시행부서원 현장 실측 → 부서장 결재 후 통보서 발급
> 💡 ex-SSOC 시스템에서는 위 "의뢰" 단계가 검측의뢰서 작성·상신(위치/CodeNo 선택, 자동 연동 등)으로 디지털화되어 있습니다.

## 3장. 현행 문제점 및 해결방안 모색

현행 검측 시스템의 한계를 진단하고, 차세대 시스템에서 이를 극복하기 위한 구체적인 기술적 해결방안을 제시합니다.

### 3.1 현행 시스템(ex-SSOC) 주요 문제점

**[1] 위치 정보 수동 입력**
STA 텍스트 타이핑으로 오타 발생 및 추후 GIS 시각화 불가.

**[2] 사진 증빙 신뢰성 부재**
촬영 위치 및 시점을 시스템적으로 검증할 수 없어 위변조 리스크 존재.

**[3] 종이 문서 기반 한계**
수기 작성된 PDF 업로드로 인해 체크리스트 단위 데이터 분석/통계 불가.

### 3.2 해결방안

**[1] 위치 정보 디지털 전환 (Sat Pointer)**
STA 수동 텍스트 → RTK cm급 GIS 좌표 자동 입력.

**[2] 사진 증빙 위변조 방지 (큐피드)**
수동 업로드 → EXIF GPS·방향각·타임스탬프 자동 추출 및 BIM 객체 교차 검증.

**[3] 체크리스트 모바일 DB화**
HWP+스캔(42MB) → 118종 CodeNo 체크리스트를 모바일 App 체크박스로 전환.

## 4장. 차세대 검측 시스템 개념도

Sat Pointer(위치 측정)·큐피드(사진 검증)·모바일 App(현장 입력)·관리자 Web(대시보드)이 검측 데이터 플랫폼으로 연동되고, CesiumJS 3D·GIS 시각화 엔진이 그 위에서 결과를 보여주는 차세대 시스템의 전체 구성도입니다.

```text
┌──────────────────────────────────────────────────────────────┐
│                차세대 통합 검측 시스템                          │
├─────────────┬─────────────┬─────────────┬────────────────────┤
│ Sat Pointer │ 큐피드      │ 모바일 App  │ 관리자 Web          │
│ (위치 측정)  │ (사진 검증) │ (현장 입력) │ (대시보드)          │
├─────────────┴─────────────┴─────────────┴────────────────────┤
│                    검측 데이터 플랫폼                          │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────────┐ │
│  │의뢰·결재 │  │체크리스트│  │참고문서  │  │검측 대시보드 │ │
│  │모듈      │  │DB 모듈   │  │자동연동  │  │(GIS 히트맵)  │ │
│  │          │  │(118종)   │  │(감사지적 │  │              │ │
│  │          │  │          │  │ 설계지침 │  │              │ │
│  │          │  │          │  │ 안전가이드│  │              │ │
│  │          │  │          │  │ +EXCS연동)│  │              │ │
│  └──────────┘  └──────────┘  └──────────┘  └──────────────┘ │
├──────────────────────────────────────────────────────────────┤
│            CesiumJS 3D + GIS 시각화 엔진                      │
└──────────────────────────────────────────────────────────────┘
```

이처럼 위치·사진·체크리스트 데이터를 입력 단계에서부터 자동으로 검증하고 하나의 플랫폼에 축적함으로써, 수기·종이 기반의 현행 방식을 데이터 기반의 신뢰성 있는 검측 체계로 전환하는 것이 차세대 시스템이 추구하는 방향입니다.
