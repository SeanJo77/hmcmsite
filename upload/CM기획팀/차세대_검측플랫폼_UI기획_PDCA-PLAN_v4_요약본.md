# 차세대 검측 플랫폼 UI 기획 v4.0 핵심 요약 (보고용)

> **작성 목적**: 바쁘신 팀장님을 위한 UI 기획 방향 및 화면 구성 요약본

---

## 1. 플랫폼 UI 설계  (Screen 1 기준)

기존 문서/리스트 중심의 흐름을 벗어나, **구조물 객체를 중심으로 즉각적인 파악과 행동이 가능

1. **객체 중심 (Object-First)**: "검측목록"에서 찾는 것이 아니라, "교각7"을 누르면 해당 객체의 검측 현황이 나오는 직관적 흐름.
2. **맥락 유지 (Context-Preserving)**: 페이지 이동 없이 한 화면 안에서 전체 교량 조망(Overview)과 특정 객체 상세(Specific) 모드를 즉시 전환.
3. **즉각 행동 (Inline Action)**: "진행 중 검측"을 확인할 때 버튼을 찾아 헤매지 않도록, 리스트 각 항목 옆에 현재 상태에 맞는 버튼(`[내용 판정]`, `[최종 승인]`, `[의뢰서 재작성]` 등)을 즉시(Inline) 배치.

| **Screen 6 & 1**<br>(검측 목록리스트 확인) | 관리자 모니터링용 리스트 개선.<br>- 스크롤이 편한 **주요 컬럼 틀고정**, 검색 필터 로컬 저장, 엑셀 다운로드                                                                           |

## 3. 핵심 개선 사항 (ex-SSOC v0.1.5 매핑 요약)

화면(Screen별) UI 변경 적용 사항 

*※ 구글 시트의 총 110개 분석 항목 중, 시스템의 패러다임을 바꾸는 핵심 UI 개선 사항입니다.*

1. **결재 과중 해소**: 상시검측(WP)은 3단계 라인 대신 자동 승인/통보하는 간소화 UI 적용 (S1, S4)
2. **문서 파기 방지**: 반려 시 문서가 폐기되던 최대 문제를 수정 모드 회귀로 전환 (S2, S4, S5)
3. **참조 팝업/이탈 제거**: BIM 모델 선택, 설계정보 열람, 참고자료 확인 등을 모두 하나의 화면(인라인, 슬라이드)에 통합하여 클릭 Depth 최소화 (S1, S3)
4. **체크리스트 상세 항목**: 추후 기획예정이나, 체크리스트 각 항목별로 시공상세도, 안전처리 관리 문서 등이 연동되도록 구현
5. **리포트 자동화**: 가독성이 떨어지던 통보서를 UI 구조와 동일한 형태의 깔끔한 PDF로 원클릭 생성 (S4, S5)
