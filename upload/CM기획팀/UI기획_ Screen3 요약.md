# [보고] 차세대 검측 플랫폼 UI 기획 및 개발 진행 현황 (체크리스트 중심)

## 1. 현재 진행 상황
- 검측의뢰서 작성(Screen 2) 화면은 현재 체크리스트와의 연동성을 높이는 방향으로 계속 보완 및 업데이트 중

## 2. 핵심 개선 방향 및 프로세스 패러다임 전환

* **업무 흐름**: `[기성객체 선택 (Screen1)]` ➔ **`[체크리스트 선행 판정 (Screen3)]`** ➔ `[검측의뢰서 자동 생성 및 상신 (Screen2)]`

## 3. 중점 UI 개선 사항 (Screen 3: 체크리스트)

### ① 스마트 트리 메뉴 (검색 피로도 최소화)
- 기존의  `대공종 > 중공종 > 소공종`의 3중 트리 메뉴를 좌측에 그대로 배치했습니다.
- 사용자가 기성객체를 선택하면, 이 기성객체에 대한 항목만 펼쳐져 있도록 하고,  현재 공정(예: 교각 벽체 철근조립)을 인지하여 **관련된 체크리스트만 자동으로 활성화(Context-Aware)**시켜 주어 불필요한 탐색 시간을 없앴습니다.
- 체크리스트 다중 체크 기능: 기존 ex-ssoc 시스템은 마지막에 체크한 항목한 UI 내 반영

### ② '해당사항 없음(N/A)' 항목의 스마트 분리 (문서 가독성 극대화)
- 기존에는 타설 전 공정인데도 '거푸집 탈형' 같은 후속 공정 검측 항목이 섞여 있어 문서가 매우 길고 혼란스러웠습니다. 
- 이를 개선하여 현재 공정에 해당하지 않는 항목들은 **우측 '해당사항 없음' 패널로 자동 분리 및 접기(Fold) 처리**하여, 사용자는 당장 점검해야 할 핵심 항목에만 집중할 수 있도록 UI를 분할했습니다. (클릭 한 번으로 언제든 본문 복구 가능) 

### ③ 인라인(Inline) 문서 뷰어 도입 및 지침서 정밀 연동 (화면 이탈 방지) : 
- **검측절차서 프로세스 연계 현황 표출**: 본문 상단에 전체 검측 프로세스 흐름도(사전/WP/HP)를 시각적으로 표기, `[📄검측절차서 원본 보기]` 
- **항목별 정밀 문서 매핑 (ex-SSOC 한계 극복)**: 기존 ex-SSOC에서는 감사지적사항, 설계실무지침, 안전가이드 등이 체크리스트 내용과 무관하게 통째로 연동 한계 -> 이를 개선하여 **체크리스트의 각 세부 점검 항목(행)별로 연관된 지침 문서만 정밀하게 1:1로 연동(매핑)**되도록 구조를 개편.
- 특정 검측 항목 옆의 `[📄문서 뷰어]` 버튼을 누르면 화면 우측 서랍(Drawer)이 열리며, 현재 점검 중인 항목에 꼭 필요한 과거 감사 지적사항이나 시방서 기준만을 화면 이탈 없이 즉시 열람하여 판정을 돕습니다.

**참고: 상세 연동 문서 기획 은 추후 예정**

### ④ 사용자 편의성 및 데이터 무결성 확보
- **일괄 처리 기능**: `[적정 일괄 체크]` 및 `[전체 일괄 복구]` 버튼을 두어 반복작업 간소화
- **권한 제어**: 의뢰자가 실수 또는 임의로 '검측자 판정'란을 건드리지 못하도록 UI 상에서 비활성화
- **체크리스트 편집 기능**: 수정/삭제는 문제 발생할 수 있으므로, 추가하는 기능만 추가

## 4. 향후 계획 (Next Step) 및 검측의뢰서(Screen 2) 진행 현황
- **현재 진행된 Screen 2 구현 내용**:
  - 우측 패널에 **Audit Log(변경 이력) 탭** : 체크리스트나 의뢰서가 어떻게 수정되고 결재 history 이력
- **상시검측(WP) 및 필수검측(HP) 맞춤형 워크플로우 적용**:
  - **상시검측(WP) 의뢰 시**: S1(기성객체 선택) ➔ **S3(체크리스트 신규 작성)** ➔ S2(의뢰서 자동 상속 및 생성)
  - **필수검측(HP) 의뢰 시**: 이미 상시검측 단계 데이터가 존재하므로, **중복되는 S3 작성을 생략하고 곧바로 S2(검측의뢰서 작성)로 직행**
- **잔여 작업 내역 (Next Step)**:
  - 현재 개발된 체크리스트(Screen 3)의 상세 판정 결과를 바탕으로, S2의 '주요 내용(점검 항목 요약)' 및 '특기 사항(부적정 사유 등)'이 **100% 자동 상속되어 동적으로 렌더링되도록 데이터 연동 및 보완 작업** 예정입니다.
